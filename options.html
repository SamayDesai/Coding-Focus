Settings

Enforcement, problem lists, allowlist, and timer

Daily LeetCode requirement

A separate daily rule, independent of the Pomodoro timer.

The assignment refreshes on the next local calendar day. Solving the exact assigned problem unlocks ordinary browsing for the rest of that day. Focus sessions may apply an additional block.

Problem collections

Random selection without repeats until the list is exhausted.

Import a problem list

Accepts plain text, CSV containing LeetCode URLs/slugs, or JSON arrays/objects with slug, url, link, or titleSlug fields. Invalid entries and duplicates are skipped.

Temporary disable

The timer expires automatically and restores the active policies.

No active bypass.

Theme and accent options are configured on the timer dashboard.

Website allowlist

Allowlisted websites remain accessible while the daily gate or focus timer is blocking the rest of Chrome.

Google Search regional hosts are exact-host entries so adding Google Search does not automatically allow Drive, YouTube, or every other Google service. Custom entries can include subdomains if desired. LeetCode remains allowed independently.

Data and permissions

All settings and timer statistics are stored locally in Chrome.

To enforce the allowlist, Chrome must let this extension redirect website navigations. This extension does not send your browsing history, problem lists, or timer history to a server.
